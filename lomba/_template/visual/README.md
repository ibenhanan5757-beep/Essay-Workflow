# Spesifikasi visual

Satu file JSON per grafik/diagram (lihat contoh di `workflow/03b-rencana-visual.md`). Buat gambarnya dengan:

```
python tools/buat_visual.py <L>/visual/*.json --profil <L>
```
Hasilnya masuk ke `<L>/draf/gambar/`. Setiap angka di grafik harus ada di peta klaim (`riset/sumber.md`).
