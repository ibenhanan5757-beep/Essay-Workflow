# Riset: sumber.md (log sumber + peta klaim, mulai dari templates/sumber.md) dan dossier.md

Folder `teks/`: teks asli dari setiap sumber yang dibaca (abstrak, bagian yang dikutip), satu file per sumber (`penulis-tahun.md`). Baris pertama: `Sumber: <URL/DOI> · diakses <tanggal> · bagian: <abstrak/hlm ...>`. Isinya hanya teks yang diambil dari sumber, bukan ringkasan sendiri. Kutipan verbatim di peta klaim disalin dari sini. Dipakai `tools/cek_naskah.py --sumber <L>/riset/teks` untuk mendeteksi kalimat yang tersalin mentah.
