# Referensi DESIGN.md

Sumber: https://github.com/VoltAgent/awesome-design-md (commit 3b60532, MIT). Setiap file di `library/<situs>/DESIGN.md` berisi token desain (warna, tipografi, radius, spasi) dan aturan gaya satu situs.

## Cara pakai
1. Pilih 1 file yang nadanya cocok dengan karya (misalnya `wired` atau `theverge` untuk editorial, `stripe` atau `linear.app` untuk rapi-teknis, `notion` untuk hangat-sederhana). Sebutkan pilihan dan alasannya dalam satu baris.
2. Pakai sebagai **acuan gaya**: palet, pasangan huruf, skala, ritme spasi, perlakuan foto. Untuk skill `hallmark` atau `impeccable`, file ini bisa disalin ke akar proyek sebagai `DESIGN.md` supaya terbaca sebagai sistem desain.
3. Sesuaikan isinya dengan karya sendiri. File ini menjelaskan tampilan, bukan isi.

## Batas
- **Jangan meniru identitas merek**: jangan memakai nama, logo, wordmark, slogan, atau aset milik situs itu. Yang dipinjam hanya prinsip gaya (warna generik, ritme, skala).
- Font berlisensi (misalnya SF Pro) diganti padanan bebas (Google Fonts) bila hasilnya akan dibagikan atau dicetak.
- Untuk lomba esai: ikuti aturan visual dari guidebook lebih dulu (ukuran, isi wajib, larangan logo/identitas). DESIGN.md hanya mengisi ruang yang tidak diatur.
